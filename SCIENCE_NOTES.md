# Nonhuman comparisons

## A named nebula

The app uses the **Stingray Nebula (Hen 3-1357)**. Hubble observations from March 1996 and January 2016 show substantial fading and structural change. The displayed approximately twenty years describes that observation interval. The source does not establish a completed birth-to-death lifespan or prove the nebula has disappeared. The leaf, list, and dialog therefore identify the quantity as an **observed fading interval**, in both languages.

- [NASA: Hubble Captures Unprecedented Fading of Stingray Nebula](https://science.nasa.gov/missions/hubble/hubble-captures-unprecedented-fading-of-stingray-nebula/)
- [NASA: Fading Stingray Nebula, with exposure dates](https://science.nasa.gov/asset/hubble/fading-stingray-nebula/)

This replaces the earlier generic planetary-nebula duration. It is not appropriate to attach that generic duration to a named object without object-specific evidence.

## Older named cosmic comparisons

The normal descending leaf list also includes these still-visible supernova remnants. Values compare the **estimated age of the remnant**, meaning elapsed time since the explosion. They do not measure the original star's lifespan or imply the remnant itself has died. The interface labels each quantity as an estimated remnant age in English and Chinese.

| Object | Approximate comparison | Source |
| --- | --- | --- |
| Spaghetti Nebula / Simeis 147 | 40,000 years | [NASA APOD](https://science.nasa.gov/image-article/apod-2022-january-13-supernova-remnant-simeis-147/) |
| Vela supernova remnant | 11,000 years | [NASA: Pencil Nebula and Vela remnant](https://science.nasa.gov/asset/hubble/the-pencil-nebula-remnants-of-an-exploded-star-ngc-2736/) |
| Jellyfish Nebula / IC 443 | 10,000 years | [NASA Fermi account](https://www.nasa.gov/universe/nasas-fermi-proves-supernova-remnants-produce-cosmic-rays/) |

Different studies can give different age estimates, particularly for IC 443. These values follow the linked outreach sources and are marked approximate. Input `100000` includes all three and sorts Simeis 147 first. Strict comparison means input `40000` does not yet include the 40,000-year entry.

## Radioactive atoms and half-lives

A radioactive isotope has an unstable nucleus and can transform through nuclear decay. Some decay modes change the chemical element; others change the nuclear state without changing the element. For example, carbon-14 transforms into nitrogen-14. Its commonly quoted approximate half-life is 5,730 years.

An individual atom's decay time is unpredictable. A half-life describes the time in which roughly half of a large population of parent nuclei decays. Roughly a quarter of the original parent nuclei remain after two half-lives. It is not a deadline at which every atom changes or a completed lifespan for an element as a whole.

If radioactive comparisons are added later, use language such as **one half-life of carbon-14**, with an explicit quantity label and source. Fractional-year half-lives will also require a comparator that preserves the current arbitrary-size integer age input without rounding the half-life incorrectly. No isotope entries have been added in this revision.
